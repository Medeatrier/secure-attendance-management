# Pruebas y limitaciones

Se adjuntan pruebas unitarias Django para algunos permisos y reglas de negocio. La sintaxis Python ha sido compilada, pero las pruebas de ejecución aún no se han verificado en un entorno con dependencias instaladas.

La exportación CSV es un intercambio genérico, sin integración activa con ninguna plataforma externa. La gestión de fotos y justificantes **no es apropiada para datos reales en un despliegue público** hasta que los archivos se almacenen de manera privada y se sirvan con autorización. Ver `docs/SECURITY_REVIEW.md`.
